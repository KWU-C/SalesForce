# 経営ダッシュボード 資金収支の分類仕様 (v3.2)

実装: `src/features/management-dashboard/journalCashFlow.ts`(分類)、`src/config/cashInflowClassification.ts` /
`cashOutflowClassification.ts` / `freeeExpenseClassification.ts`(科目・ルール)。データ源はfreeeの仕訳帳CSV。

## 検算
月初現預金 + キャッシュイン − キャッシュアウト = 月末現預金。差は調整せず「検算差額」として表示する。

## 給与・人件費(旧称: 人件費)
給与・人件費 = 従業員給与 + 従業員賞与 + 役員報酬・役員賞与 + 退職金 + 指定業務委託

| 内訳 | 内容 |
|---|---|
| 従業員給与 | 給料手当・雑給など(役員・賞与・退職金以外の給与・人件費科目) |
| 従業員賞与 | 賞与・[製]賞与 |
| 役員報酬・役員賞与 | 役員報酬・役員賞与、取締役の給与振込、「【給与】」の現金渡し |
| 退職金 | 退職金・[製]退職金(従業員)。元副社長の未払退職金は借方が「長期借入金」のため借入元本返済のまま |
| 指定業務委託 | 松田徹・福場幸司郎・日比由美(元社員で契約社員的な位置付け。業務委託費から移す) |

### うち従業員給与計(参考内訳行)
**うち従業員給与計 = 従業員給与 + 従業員賞与 + 指定業務委託(松田徹・福場幸司郎・日比由美)**

役員報酬・役員賞与、退職金、社会保険(税金・社会保険等)、福利厚生費(諸経費)は含めない。
給与・人件費の内数であり、支出合計へ二重加算しない。金額は源泉徴収後の現金支払額。

### 指定業務委託の判定
- 主キー: 未払金・買掛金の補助科目(取引先名)の完全一致。
- 副キー: 現金の直接払いでは、業務委託費の借方の補助科目(品目名)が「【業務委託】{氏名}/」で始まる。
- 自由記述の摘要による氏名判定は使わない(別の取引先の摘要に氏名が出るため)。
- 仕訳帳CSVに取引先IDが無いため氏名で照合する。氏名が変わると一致しなくなり、その分は業務委託費として「その他」に残る。

## 外注加工費と業務委託費(v3.2、2026-09-28)
旧「外注費」を「外注加工費」に改称し、業務委託費を外した。営業上の外注(仕入れて売値を付ける外注)は「[製]外注加工費」。

| 科目 | 区分 |
|---|---|
| [製]外注加工費(外注費・外注加工費も同じ) | 外注加工費 |
| 業務委託費・[製]業務委託費のうち指定業務委託 | 給与・人件費(v3.1と同じ) |
| 業務委託費・[製]業務委託費のうちTCDマザー | 諸経費(参考内訳行「うちTCDマザー」) |
| 上記以外の業務委託費・[製]業務委託費 | その他 |

### TCDマザーの判定
- 主キー: 未払金・買掛金の補助科目(取引先名)が「有限会社ティーシーディマザー」に完全一致。
- 副キー: 業務委託費の借方の補助科目(品目名)が「【業務委託】ティーシーディーマザー」で始まる。
- 摘要・伝票単位では判定しない(TCDマザーと指定業務委託を1つの振込伝票で払っているため)。
- 「うちTCDマザー」は業務委託費だけ。地代家賃などTCDマザーへの他の支払は含まない。

49期(支払ベース): 外注加工費 ¥77,898,705 / うちTCDマザー ¥18,469,257 / その他へ ¥1,431,015。
3つの合計は旧外注費と一致する(指定業務委託 ¥10,586,210 はv3.1から給与・人件費)。

## 営業キャッシュ収支
営業キャッシュ収支 = 営業入金 − 営業支出(給与・人件費 + 外注加工費 + 税金・社会保険等 + 諸経費 + その他)。
借入・保険資産回収等・その他入金、借入元本返済・支払利息・積立資産移動・未分類の出金は含めない。
指定業務委託・退職金を給与・人件費へ、業務委託費を諸経費(TCDマザー)・その他へ移しても営業支出合計は変わらない(旧区分の整数金額を保存する二段階按分)。
